# Para Catalina 🌻

Una página web romántica, interactiva y poética creada como una carta digital animada para Catalina.

## 🌻 Características

- **Pantalla Inicial:** Bienvenida cálida y personalizada ("Antes de comenzar, dime tu nombre ✨").
- **Animación de Girasoles:** Crecimiento y florecimiento animado de girasoles con efectos de partículas doradas.
- **Ilustración Animada:** Retrato en estilo arte digital/Ghibli de Catalina con su pelirrojo cabello y su gato mishi moscado.
- **Opción de foto personalizada:** Permite cambiar fácilmente la foto de referencia por cualquier otra imagen.
- **Mensaje Final & Carta:** Carta romántica con notas desplegables, lluvia de luces y música ambiental de fondo.
- **Diseño Responsive:** Adaptado para celular, tablet y computador.

## 🚀 Cómo ejecutar en local

1. Clonar el repositorio:
   ```bash
   git clone <URL_DE_TU_REPOSITO>
   cd para-catalina
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Abrir en el navegador: [http://localhost:3000](http://localhost:3000)

## 🛠️ Tecnologías Utilizadas

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion / Motion
- Lucide React Icons
- Canvas Confetti
- Web Audio API (Sintetizador de música romántica)
